# LX Music Mod

基于 [LX Music Mobile](https://github.com/lyswhut/lx-music-mobile) 的深度增强修改版。

## 新增功能

### 🎨 视觉特效系统
- **粒子星空** — 80个白色粒子全屏飘散闪烁
- **音域回响** — 40×6 3D波形网格 + 流星轨迹 + 涟漪波纹
- **音频频谱** — 16柱模拟频谱条(深色底座)
- **星云壁纸** — Canvas 粒子系统 WebView 沉浸背景
- **3D歌词** — 倾斜 + 发光 3D 歌词效果
- **幻灯片背景** — 循环切换本地图片背景
- **歌词发光** — 当前行歌词 shadow/glow 效果
- **镜头震动** — 播放时随机位移/旋转动画
- **白色粒子** — 30个呼吸闪烁高光粒子
- **模糊遮罩** — 磨砂半透明覆盖层降权背景色
- **封面增强** — 阴影 + 发光双层效果
- **控制按钮呼吸光晕** — 播放时按钮呼吸发光环

### 🎨 播放器界面重新设计
- **自动对比色** — 根据背景亮度自动切换黑/白文字
- **所有文字控件可见性** — 在任何背景上都清晰可读
- **360° 跟手旋转** — 壁纸封面支持手指滑动360度旋转
- **文字阴影** — 歌词添加阴影提高可读性

### 🚗 方向盘按键控制
- 监听 `MEDIA_BUTTON` 广播
- 上一曲 / 下一曲 / 播放暂停 / 音量控制
- 车机应用启动时自动激活

### 📥 下载管理器
- **下载队列持久化** — 重启应用不丢失
- **详细进度追踪** — 实时百分比 + 进度条
- **下载目录配置** — 自定义保存路径
- **文件冲突处理** — 覆盖/跳过 可选
- **ID3 标签写入** — 下载后自动嵌入封面/歌词/元数据
- **点击播放** — 单击已下载文件直接播放
- **长按分享** — 长按弹出文件分享

### 📂 本地音乐播放器
- **递归扫描** — 自动扫描所有子目录音频文件
- **自定义目录** — 选择任意文件夹扫描
- **扫描结果持久化** — 重启应用不丢失
- **即时播放** — 点击歌曲立即切换播放列表并播放

### 🎵 批量下载
- **歌单详情页** — "下载全部"按钮一键下载列表所有歌曲
- **试听列表** — 长按歌曲菜单添加下载选项

### 🎭 封面样式
- 圆形 / 方形 / 圆角 / 黑胶唱片
- 发光光环特效
- 星河粒子特效
- 旋转动画
- 上下滑动切歌

### ⏱ 定时器
- 从播放器设置弹窗快速访问
- 定时停止播放

### 🔊 其他
- 上下滑动手势切歌
- 封面外圈呼吸发光
- 歌词居中对齐
- 流光进度条(渐变填充 + 高亮层 + 呼吸发光点)

## 导航菜单新增页面

```
搜索 → 歌单 → 排行榜 → 我的列表 → 本地音乐 → 下载管理 → 设置
```

## 编译

参照[源码使用方法](https://lyswhut.github.io/lx-music-doc/mobile/use-source-code)设置开发环境。

```bash
npm install
npm run bundle-android
cd android && ./gradlew assembleDebug
```

输出 APK 位置:`android/app/build/outputs/apk/debug/lx-music-mobile-v1.8.4-arm64-v8a.apk`
